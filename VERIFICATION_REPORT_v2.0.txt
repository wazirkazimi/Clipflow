FEATURE 2: SMART GAMEPLAY ROTATION

  Description: Automatically distribute different gameplay across clips
  
  Algorithm:
    1. Get list of available gameplay videos
    2. Create cycle iterator: cycle(gameplay_list)
    3. For each clip: next(gameplay_cycle)
    4. Result: Round-robin distribution
  
  Example (7 clips, 7 gameplay videos):
    clip_0 → gameplay_list[0]  (subway_surfer)
    clip_1 → gameplay_list[1]  (mc_parkour)
    clip_2 → gameplay_list[2]  (temple_run)
    clip_3 → gameplay_list[3]  (nfs_car)
    clip_4 → gameplay_list[4]  (minecraft_parkour)
    clip_5 → gameplay_list[5]  (ramp_car)
    clip_6 → gameplay_list[6]  (bgmi)
